# Hoard

A colourful, fast disk-space explorer TUI written in C#. The user documentation is in `docs/` (GitHub Pages) and `README.md`. Screenshots in `docs/images/` are generated from the real app by `tools/Hoard.Screenshots` (`dotnet run --project tools/Hoard.Screenshots`); regenerate them when screens change.
